How to type it
  • Notes: d r m f s l t. Sharps: de re fe se le. Flats: ra ma sa la ta.
  • Lower octave: t_ or t1. Higher octave: d'.
  • : is a full beat, . a half beat, , a quarter beat, ., a three-quarter beat then a quarter.
  • - holds the note. An empty beat is a rest. | is a bar line.
  • For several voices, put Part: Soprano, Part: Alto and so on before each line group.
  • Start with Key: G if Doh is G, and Tempo: 90 to set the speed.
